# Запуск и устройство Gather

[← Обзор проекта](../README.md)

## Архитектура

1. **Explorer** исследует HTML и проверяет CSS-селекторы минимум на двух документах. Результат — `CrawlPlan` с областью обхода, паттернами URL, селекторами и лимитом страниц.
2. **Rust-движок** (Spider, reqwest, scraper) массово обходит сайт по плану без LLM и пишет JSONL. Tantivy индексирует заголовки и текст для BM25.
3. **Python** связывает анализ, сбор и индексацию через LangGraph; связь с Rust — PyO3 и maturin. Отдельно работают [Dense и Hybrid](retrieval.md), [подготовка разметки и оценка](evaluation.md).
4. **Gather** обслуживает React UI и FastAPI с одного адреса. Сбор, подготовка Dense, сравнение и оптимизация выполняются в отдельных процессах, не зависящих от открытой вкладки. Прогресс — этапы и доступные счётчики, не проценты и не ETA.

## Конфигурация и запуск

Команды выполняются из корня репозитория. Установка и запуск UI — в [быстром старте](../README.md#быстрый-старт). Если не установлен `just`: `cargo install just --locked`.

Для операций с LLM настройте `.env`:

```dotenv
LLM_API_KEY=your-api-key
LLM_BASE_URL=https://your-provider.example/v1
```

Модель и бюджеты агента задаются в [`config.toml`](../config.toml); `LLM_BASE_URL` переопределяет `llm.base_url`. Другой TOML можно передать через `just --set app_config custom.toml …`. Обход по готовому плану, индексация и поиск не требуют ключа. Таймауты и параллелизм обхода пока заданы в Rust.

Для разработки запустите `just ui` и `just ui-dev` в отдельных терминалах. Vite проксирует `/api` на порт 8000.

### Docker

```bash
docker build -t mas-crawler .
docker run -d --name mas-crawler \
  -p 127.0.0.1:8000:8000 \
  -v mas-crawler-data:/data --env-file .env mas-crawler
```

Откройте <http://127.0.0.1:8000>. Запуски сохраняются в volume. Для работы без LLM уберите `--env-file .env`. Это контейнер Gather, не [экспорт отдельного поисковика](retrieval.md#экспорт-bm25).

## Сбор через CLI

```bash
just analyze https://doc.rust-lang.org/std/index.html \
  --goal "Собрать документацию стандартной библиотеки Rust" \
  --output crawl-plan.json
just build --plan crawl-plan.json --run-dir runs/from-plan
just search --index runs/from-plan/index --query "Iterator" --top-k 5
```

Перед сбором проверьте `scope_prefix`, `document_url_patterns`, CSS-селекторы и `max_pages`. Для анализа и сбора одной командой используйте `just build URL --goal "…" --run-dir runs/new`. Чтобы заодно получить задания на разметку, используйте [`just dataset`](evaluation.md#подготовка-пакета).

| Артефакт запуска | Назначение |
| --- | --- |
| `crawl-plan.json` | Правила обхода и извлечения |
| `corpus.jsonl` | Документы (`url`, `title`, `text`) |
| `crawl-report.json` | Успешные загрузки, ошибки, достижение лимита |
| `index/` | Индекс Tantivy |
| `result.json` | Итоговые пути и число документов |

Каталог запуска должен быть новым; существующие файлы плана и корпуса не перезаписываются. UI автоматически видит запуски из `runs/`. Ошибки отдельных страниц не мешают индексировать успешно собранные документы; пустой корпус останавливает сборку. После сбоя могут остаться частичные артефакты; возобновления нет.

Один план рассчитан на один шаблон документов. Сбор работает с HTML из HTTP-ответов, без выполнения JavaScript и авторизации. Нет повторов неудачных загрузок, дедупликации по содержимому и инкрементального обновления. Индексатор загружает корпус в память.

## Диагностика и проверки

При ошибке фонового задания смотрите `worker.log`: у сбора — в каталоге запуска, у операций поиска и оценки — в `runs/<run_id>/retrieval/jobs/<job_id>/`. Там же сохраняются этапы и счётчики поисковых операций. На источник одновременно допускается одна такая операция; удаление его компонентов на это время блокируется.

Для трасс анализа и сборки через LangSmith добавьте в `.env`:

```dotenv
LANGSMITH_TRACING=true
LANGSMITH_API_KEY=your-langsmith-api-key
LANGSMITH_PROJECT=mas-crawler
LANGSMITH_ENDPOINT=https://api.smith.langchain.com
```

Ищите трассы `explore_site` и `build_search_system`; CLI сохраняет `trace-id.txt` для сборки. Постраничного прогресса Rust-обхода в трассах нет. Трассировка может передавать HTML и сообщения модели в облако.

- `just check` — линтер, форматирование и тесты Python/Rust; останавливается при первой ошибке.
- `just fmt` — форматирование с изменением файлов.
- `npm --prefix frontend run test:e2e` — сборка UI и браузерные проверки с подменёнными API-ответами. Нужен Chromium (`/usr/bin/chromium` или путь из `CHROMIUM_PATH`).
- `just` — список рецептов; у прикладных команд есть `--help`.
